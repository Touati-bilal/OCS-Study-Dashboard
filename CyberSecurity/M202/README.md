# M202 - Appliquer les méthodologies des tests d'intrusions

> **Durée :** 105 Heures
> **Coefficient :** 3
> **EFM Régional :** Oui

---

# Présentation

Ce module est consacré à l'apprentissage et à l'application des méthodologies professionnelles de tests d'intrusion.

Il couvre l'ensemble du cycle de vie d'un test d'intrusion, depuis la phase de planification et de reconnaissance jusqu'à l'identification des vulnérabilités, leur exploitation dans un environnement contrôlé, ainsi que la rédaction d'un rapport professionnel.

---

# Objectifs du Module

À la fin de ce module, je dois être capable de :

* Comprendre les méthodologies professionnelles de tests d'intrusion.
* Planifier et réaliser une mission de test d'intrusion.
* Identifier les vulnérabilités d'un système d'information.
* Exploiter les vulnérabilités dans un environnement contrôlé.
* Analyser les résultats d'un test d'intrusion.
* Rédiger un rapport professionnel de test d'intrusion.

---

# Structure du Module

## Partie 1

Découvrir les méthodologies de test d'intrusion

## Partie 2

Identifier les vulnérabilités au sein d'un système d'information

## Partie 3

Exploiter les vulnérabilités au sein d'un système d'information

## Partie 4
